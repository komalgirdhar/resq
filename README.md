# 🐾 RESQ - Animal Rescue Reporting Platform

**RESQ** is a mobile-first Progressive Web App (PWA) designed to make reporting animal rescue cases simple, accessible, and organized.

The platform allows users to report animals that may be injured, sick, trapped, abandoned, or in danger, helping create a structured way to communicate rescue-related information.

## ✨ Features

* 🐕 Report animal rescue cases
* 🚨 Select the type of emergency/problem
* 📍 Provide relevant location information
* 📝 Submit detailed rescue reports
* 📬 Form submission and receiving through **Forminit**
* 📱 Mobile-first responsive design
* ⚡ Progressive Web App (PWA) support
* 🌐 Works across modern browsers
* 📦 Service worker and caching support

## 🛠️ Technologies Used

* **HTML5** - Structure
* **CSS3** - Styling and responsive design
* **JavaScript (ES6+)** - Functionality and interactions
* **Forminit** - Form submission and backend handling
* **PWA** - Installable web-app experience
* **Service Worker** - Caching and offline support

## 🎯 Project Goals

RESQ was created with the goal of making animal rescue reporting more accessible through a simple, responsive, and user-friendly digital platform.

The project also explores how Progressive Web App technologies can be used to create lightweight applications that work effectively across different devices.
